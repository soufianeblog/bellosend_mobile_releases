# BelloSend for Android

Download the BelloSend app for Android.

**[Download the latest version](https://github.com/soufianeblog/bellosend_mobile_releases/releases/latest/download/bellosend-latest.apk)**

Every release is listed under [Releases](https://github.com/soufianeblog/bellosend_mobile_releases/releases).

## Installing

1. Open the downloaded file on your phone.
2. Android will ask whether to allow installing from this source — allow it.
3. Once installed, BelloSend keeps itself up to date: it offers each new
   version from **Settings → About**.

Android 7.0 or newer is required.
